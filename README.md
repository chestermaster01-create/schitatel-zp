# Payroll Partner

создай приложение для расчета зарплат сотрудников. В нем можно расчитывать зарплату которая должна меняться на основе размера выручки за месяц. можно добавлять сотрудников, можно указывать их выручку за каждый день месяца. за месяц должно считаться автоматически и показываться зарплата из расчета 1700 умноженное на количество рабочих дней(дней с выручкой у конкретного сотрудника)
